Every file is checksummed at its source before copying. From a clone, run:

```
python3 export/skillexport.py verify --repo .
```

## Refresh

`export/skillexport.py` rebuilds the export: `cloud` reads a Cowork skill and plugin sync cache, `mac` copies the sources listed in `export/sources.tsv` from the consulting folder, then `scan`, `index` and `verify`. Run `python3 export/skillexport.py --help` for arguments. `export/excludes.txt` holds the exclusion patterns.
